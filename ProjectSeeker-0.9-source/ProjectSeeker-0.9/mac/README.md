# Project Seeker for Mac

A local library of FL Studio and Ableton Live projects, with search, Bubble map, an audio player, albums, playlists, and an optional assistant. Original projects and samples are read without being modified.

The Mac edition is based on the source code updated on November 9, 2026. Two native packages are available: Apple Silicon (arm64) and Intel (x86_64). See [the Mac guide](MAC_GUIDE.md) for installation instructions, limitations, and verification details. See [the assistant documentation](ASSISTANT.md) for its features, privacy rules, and limitations.

The Build Mac workflow creates DMG packages and SHA-256 checksums on GitHub's servers. Build artifacts remain private; no release is published automatically. The apps use ad hoc signatures, without an Apple Developer ID or notarization.
